# Changelog

## 1.0.0 — 2026-09-30

Stable read-only inspector for JavaScript object graphs, including real JavaScript types, circular and shared references, descriptor-safe discovery, controlled expansion and selection, bounded search, grouped large values, keyboard navigation, scoped styling, targeted slots, custom types and actions, classic presentation, and unstyled mode.

The stable contract supports React 18.3 and React 19, TypeScript, ESM and CommonJS, server rendering and hydration. Package verification now installs the exact tarball into isolated React 18 and 19 consumers, enforces the public archive inventory and size budgets, and prevents machine-level npm configuration from affecting release evidence.

Publication uses a separately verified artifact, npm trusted publishing, provenance, and a protected release workflow. Automated unit, browser, accessibility, website, package, and benchmark coverage accompanies the release; the remaining human assistive-technology and physical-device qualification work is documented in [release readiness](docs/release-readiness.md).

## 0.1.0-beta.0 — 2026-09-07

Initial read-only inspector with real JavaScript types, circular/shared reference tracking, descriptor-safe child discovery, grouped large values, bounded search, controlled expansion and selection, copying, keyboard navigation, CSS variables, slots, custom types/actions, and unstyled mode.

Includes a documentation/playground site, React 18/19 test matrix, SSR/hydration checks, three-engine browser coverage, package checks and reproducible benchmarks. Release classification and outstanding manual validation are recorded in docs/release-readiness.md.

Reference text is directly actionable and jumps select the original node. Enter activates branches/references, Space selects, and search supports Enter/Shift+Enter navigation.

Adds a dedicated playground with predefined type scenarios, standalone live-update examples, customization controls, large-data and lazy-child demonstrations, opt-in measurements, shareable configurations and a manual validation checklist.

Adds seeded random updates for complex service graphs, optional application-owned update pulses with reduced-motion support, and expanded CSS typography/spacing/color controls.
